02 / PRIMARY IDENTITY

Keep the signature intact.

Use the original artwork, a deliberate type pairing, and three recognizable colors.

THE ORIGINAL WORDMARK
Original artwork. Always.Download SVG ↗

A mark for every context.

The horizontal wordmark is the compact signature. Filled and outlined organic versions create a self-contained presence. Use dispersed-letter versions at a scale that preserves legibility.

Never retype, stretch, redraw, rearrange, or add effects to the logo.

Clear space, size testing & co-branding +

Give it space.

Proposed: use the apostrophe height as x around the horizontal wordmark; use ¼ of the shape height for organic versions. Confirm against master artwork.

Test at actual size.

Print and view every variation at its intended size. Check counters, thin strokes and letter separation. Minimum production sizes remain pending testing.

Balance partners.

Match perceived visual weight, not bounding-box dimensions. Keep each original mark distinct. Label the Aesop and Slowear concepts as speculative.
