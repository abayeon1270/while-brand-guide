06 / AI PROMPT GUIDE

Human direction.
Considered execution.

The designer sets creative intent and approves the result. AI works within the established system.

PERMANENT

Keep the foundation.

Purpose, audience, values, original logos, authentic typography, approved colors, warm voice, and asset fidelity.

FLEXIBLE

Adapt the application.

Format, composition, scale, crop, placement, context, camera angle and project-specific production needs.

Recommended tools & responsibilities +

ChatGPT

Briefs, copy alternatives and prompt structure. Review facts, meaning and voice.

Image generation

Exploratory scenes and visualizations. Apply original logos and authentic text in final artwork.

Codex

Responsive implementation and repeatable checks. Test functionality, layout and accessibility.

Production tools

Illustrator, InDesign and compositing for master assets and final typography. These are production tools, not generative models.

Recommended workflow pending brand-owner approval. Record the tool/model, date, input assets, prompt, revisions and reviewer for each project.

Build from the same foundation.

REUSABLE PROMPTS
Structure: Brand foundation → Project brief → Visual direction → Deliverables → Review criteria. Each application card includes its context and example output.


ENCOURAGE
Warm. Clear. Real.
Gentle invitations, small portions, believable textures, intimate settings, supplied artwork, and careful typography.
“Try this next.” “A little more time together.” “Notice what changes.”
REJECT
Identity drift.
Altered logos, simulated fonts, invented facts, unsupported claims, rushed language, unrelated symbols, decorative excess and false official partnerships.
Avoid “hurry,” “ultimate luxury,” and exaggerated marketing superlatives.
